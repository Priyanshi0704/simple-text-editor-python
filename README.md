# 📝 Simple Text Editor (Python Tkinter)

A lightweight desktop text editor built using Python and Tkinter.
This project demonstrates GUI development, file handling, and event-driven programming.

## 🚀 Features

* Create new file
* Open existing text files
* Save files
* Simple and clean UI
* Menu-driven controls

## 🛠️ Tech Stack

* Python
* Tkinter (GUI)
* File Handling
